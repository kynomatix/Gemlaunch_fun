## 🚨 CRITICAL SEVERITY FINDINGS

### CRITICAL-1: Race Conditions in State Transitions

**Location**: `services/graduation_state_manager.py` (Lines 242-340)  
**Severity**: CRITICAL  
**Risk**: Transaction ordering attacks, state corruption

**Issue**:
The state machine lacks atomic transaction guarantees during graduation. Consider this attack scenario:

```python
# Current vulnerable code flow:
def initiate_graduation(token):
    token.graduation_status = 'initiating'  # State change
    db.session.commit()                      # Committed BEFORE transaction
    
    tx_hash = blockchain.send_transaction()  # Can fail after state change
    token.graduation_initiation_tx = tx_hash
    db.session.commit()
```

**Attack Vector**:
1. User A initiates graduation (status → 'initiating')
2. Database commits before blockchain transaction
3. Blockchain transaction fails due to gas/network
4. Token stuck in 'initiating' status with no transaction hash
5. Trading frozen permanently unless manual intervention

**Exploitation**:
- Malicious actor can deliberately cause transaction failures
- DOS attack on token trading by forcing failed graduations
- Users unable to trade during stuck state

**Recommendation**:
Implement two-phase commit pattern with transaction rollback:

```python
def initiate_graduation(token):
    """Atomic graduation initiation with rollback"""
    # Start database transaction
    db.session.begin_nested()
    
    try:
        # 1. Update status
        token.graduation_status = 'initiating'
        token.graduation_initiated_at = datetime.now(timezone.utc)
        
        # 2. Send blockchain transaction BEFORE committing state
        tx_hash = blockchain.send_transaction(
            timeout=30,  # Add timeout
            gas_limit=500000,  # Set explicit gas limit
            max_retries=3
        )
        
        # 3. Wait for transaction confirmation
        if not blockchain.wait_for_confirmation(tx_hash, timeout=60):
            raise Exception("Transaction not confirmed")
        
        # 4. Only NOW commit database state
        token.graduation_initiation_tx = tx_hash
        db.session.commit()
        
        return {'success': True, 'tx_hash': tx_hash}
        
    except Exception as e:
        # Rollback ALL changes including status
        db.session.rollback()
        
        # Log failure for monitoring
        logger.error(f"Graduation initiation failed: {str(e)}")
        
        # Mark as failed only if transaction was confirmed
        # but subsequent steps failed
        if 'tx_hash' in locals():
            token.graduation_status = 'failed'
            token.graduation_initiation_tx = tx_hash
            db.session.commit()
        
        return {'success': False, 'error': str(e)}
```

**Additional Requirements**:
- Add distributed lock mechanism to prevent concurrent graduation attempts
- Implement idempotency keys for transaction deduplication
- Add circuit breaker for blockchain RPC failures
- Create monitoring alerts for stuck graduations

**Impact if Not Fixed**: HIGH  
Tokens can become permanently untradeable. Platform reputation damage.

### CRITICAL-3: No MEV Protection Strategy

**Location**: System-wide  
**Severity**: CRITICAL  
**Risk**: Systematic value extraction from users via front-running

**Issue**:
The specification has zero mention of MEV (Maximal Extractable Value) protection. On public blockchains, ALL transactions in mempool are visible before execution. Sophisticated bots can:

1. **Front-run buys**: See user buying X tokens → Buy before user → User pays higher price
2. **Sandwich attacks**: Front-run with buy + Back-run with sell → Extract profit from user's trade
3. **Back-run sells**: See user selling X tokens → Sell before user → User receives less

**Real Attack Scenario**:
```
Block N:
  1. User submits: Buy 10,000 tokens (pays 5 KAS)
  2. Bot sees transaction in mempool
  3. Bot submits: Buy 10,000 tokens (gas price +20%)
  4. Bot's tx executes first (higher gas)
  5. Price now higher due to bot's buy
  6. User's tx executes at worse price (pays 5.5 KAS instead of 5)
  7. Bot submits: Sell 10,000 tokens
  8. Bot profits 0.5 KAS from user
```

**Why This Matters**:
- Professional MEV bots scan ALL DEX transactions
- Kaspa Finance is a public DEX → fully exposed to MEV
- Users unknowingly pay "invisible tax" on every trade
- Platform reputation suffers when users realize

**Recommendation**:
Implement multi-layered MEV protection:

### CRITICAL-4: Missing Price Oracle Validation

**Location**: `services/web3_service.py` (Lines 460-550)  
**Severity**: CRITICAL  
**Risk**: Price manipulation, arbitrage exploitation

**Issue**:
The quote system blindly trusts QuoterV2 contract responses with zero validation:

```python
# Line 490-510 - NO VALIDATION
def get_buy_quote_dex(self, token, kas_amount):
    quote_response = quoter_contract.functions.quoteExactInputSingle((
        WKAS_ADDRESS,
        token.contract_address,
        kas_amount,
        token.dex_pool_fee_tier,
        0
    )).call()
    
    return quote_response[0]  # ← Returns amount directly, no checks!
```

**Attack Vectors**:

1. **Price Oracle Manipulation**:
```
Attacker's sequence:
1. Flash loan large amount of KAS
2. Buy massive amount of token on DEX
3. Price artificially inflated in pool
4. Victim user requests quote → sees inflated price
5. Victim makes bad trade decision
6. Attacker dumps tokens
7. Attacker repays flash loan with profit
```

2. **Stale Price Exploitation**:
```
1. Pool price moves significantly
2. Quote fetched from old block (network delay)
3. User shown outdated price
4. User executes trade at worse price
5. Arbitrageurs profit from price difference
```

3. **Pool Manipulation via Low Liquidity**:
```
1. Graduated token has low liquidity ($10k)
2. Single whale trade moves price 20%
3. Quote system doesn't detect abnormality
4. Regular users get bad prices
```

**Recommendation**:
Implement multi-source price validation:

```python
# services/price_oracle.py (NEW)

class PriceOracle:
    """Validates DEX quotes against multiple sources"""
    
    def __init__(self):
        self.max_price_deviation = 0.05  # 5% max deviation
        self.quote_timeout = 30  # seconds
        self.min_liquidity_usd = 5000  # Minimum pool liquidity
    
    def get_validated_quote(self, token, amount, is_buy):
        """Get quote with multi-source validation"""
        
        # 1. Get primary quote from QuoterV2
        primary_quote = self.get_quoter_quote(token, amount, is_buy)
        
        # 2. Get reserve-based quote (independent calculation)
        reserves_quote = self.calculate_quote_from_reserves(token, amount, is_buy)
        
        # 3. Get recent trade-based price
        recent_trades_price = self.get_recent_average_price(token)
        
        # 4. Get TWAP (Time-Weighted Average Price) if available
        twap_price = self.get_twap_price(token, period=600)  # 10 min TWAP
        
        # 5. Validate all sources agree
        validation_result = self.validate_price_consistency({
            'quoter': primary_quote,
            'reserves': reserves_quote,
            'recent_trades': recent_trades_price,
            'twap': twap_price
        }, amount, is_buy)
        
        if not validation_result['valid']:
            raise PriceManipulationDetected(
                f"Price inconsistency detected: {validation_result['reason']}"
            )
        
        # 6. Check pool health
        pool_health = self.check_pool_health(token)
        if not pool_health['healthy']:
            raise InsufficientLiquidityError(
                f"Pool health check failed: {pool_health['reason']}"
            )
        
        return {
            'amount_out': primary_quote,
            'validation': validation_result,
            'pool_health': pool_health,
            'confidence': validation_result['confidence']  # High/Medium/Low
        }
    
    def validate_price_consistency(self, quotes, amount, is_buy):
        """Check if all price sources agree within tolerance"""
        
        prices = []
        
        # Convert all quotes to price per token
        if quotes['quoter']:
            prices.append(quotes['quoter'] / amount)
        if quotes['reserves']:
            prices.append(quotes['reserves'] / amount)
        if quotes['recent_trades']:
            prices.append(quotes['recent_trades'])
        if quotes['twap']:
            prices.append(quotes['twap'])
        
        if len(prices) < 2:
            return {
                'valid': False,
                'reason': 'Insufficient price sources',
                'confidence': 'low'
            }
        
        # Calculate price deviation
        avg_price = sum(prices) / len(prices)
        max_deviation = max(abs(p - avg_price) / avg_price for p in prices)
        
        if max_deviation > self.max_price_deviation:
            return {
                'valid': False,
                'reason': f'Price deviation {max_deviation:.2%} exceeds {self.max_price_deviation:.2%}',
                'confidence': 'low',
                'prices': prices,
                'avg_price': avg_price
            }
        
        # Determine confidence based on agreement
        if max_deviation < 0.01:  # < 1% deviation
            confidence = 'high'
        elif max_deviation < 0.03:  # < 3% deviation
            confidence = 'medium'
        else:
            confidence = 'low'
        
        return {
            'valid': True,
            'reason': 'All sources agree',
            'confidence': confidence,
            'max_deviation': max_deviation,
            'avg_price': avg_price
        }
    
    def calculate_quote_from_reserves(self, token, amount_in, is_buy):
        """Independent quote calculation from pool reserves"""
        
        # Get reserves directly from pool contract
        pool_contract = self.web3.eth.contract(
            address=token.dex_pool_address,
            abi=POOL_ABI
        )
        
        reserves = pool_contract.functions.getReserves().call()
        reserve0, reserve1 = reserves[0], reserves[1]
        
        # Determine which is token vs KAS
        token0 = pool_contract.functions.token0().call()
        if token0.lower() == token.contract_address.lower():
            token_reserve = reserve0
            kas_reserve = reserve1
        else:
            token_reserve = reserve1
            kas_reserve = reserve0
        
        # Calculate quote using constant product formula
        # x * y = k
        # amount_out = (amount_in * reserve_out) / (reserve_in + amount_in)
        
        fee_multiplier = 1 - (token.dex_pool_fee_tier / 1000000)  # Fee tier to decimal
        
        if is_buy:
            # Buying tokens with KAS
            amount_in_with_fee = amount_in * fee_multiplier
            amount_out = (amount_in_with_fee * token_reserve) / (kas_reserve + amount_in_with_fee)
        else:
            # Selling tokens for KAS
            amount_in_with_fee = amount_in * fee_multiplier
            amount_out = (amount_in_with_fee * kas_reserve) / (token_reserve + amount_in_with_fee)
        
        return int(amount_out)
    
    def get_recent_average_price(self, token, num_trades=10):
        """Get average price from recent trades"""
        
        # Query last N swaps from database
        recent_swaps = Trade.query.filter(
            Trade.token_id == token.id,
            Trade.created_at >= datetime.now(timezone.utc) - timedelta(minutes=30)
        ).order_by(Trade.created_at.desc()).limit(num_trades).all()
        
        if len(recent_swaps) < 3:
            return None  # Not enough data
        
        # Calculate volume-weighted average price
        total_volume = sum(swap.kas_amount for swap in recent_swaps)
        if total_volume == 0:
            return None
        
        weighted_price = sum(
            (swap.kas_amount / swap.token_amount) * swap.kas_amount 
            for swap in recent_swaps
        ) / total_volume
        
        return weighted_price
    
    def get_twap_price(self, token, period=600):
        """Get Time-Weighted Average Price from pool"""
        
        # If pool supports TWAP oracles, use them
        pool_contract = self.web3.eth.contract(
            address=token.dex_pool_address,
            abi=POOL_ABI
        )
        
        try:
            # Try to get TWAP from pool (if supported)
            current_block = self.web3.eth.block_number
            lookback_block = current_block - (period // 12)  # Assuming 12s blocks
            
            price_cumulative_current = pool_contract.functions.price0CumulativeLast().call()
            price_cumulative_past = pool_contract.functions.price0CumulativeLast().call(
                block_identifier=lookback_block
            )
            
            time_elapsed = period
            twap = (price_cumulative_current - price_cumulative_past) / time_elapsed
            
            return twap
            
        except Exception as e:
            logger.debug(f"TWAP not available for pool: {str(e)}")
            return None
    
    def check_pool_health(self, token):
        """Verify pool has sufficient liquidity and is functioning"""
        
        # Get pool reserves
        pool_contract = self.web3.eth.contract(
            address=token.dex_pool_address,
            abi=POOL_ABI
        )
        
        reserves = pool_contract.functions.getReserves().call()
        reserve0, reserve1 = reserves[0], reserves[1]
        
        # Calculate total liquidity in USD (simplified)
        kas_reserve = max(reserve0, reserve1)  # Assume larger reserve is KAS
        kas_price_usd = 0.15  # Example: $0.15 per KAS
        total_liquidity_usd = (kas_reserve / 1e18) * kas_price_usd * 2
        
        # Check minimum liquidity
        if total_liquidity_usd < self.min_liquidity_usd:
            return {
                'healthy': False,
                'reason': f'Insufficient liquidity: ${total_liquidity_usd:.2f} < ${self.min_liquidity_usd}',
                'liquidity_usd': total_liquidity_usd
            }
        
        # Check reserves ratio isn't extreme (potential manipulation)
        ratio = reserve0 / reserve1 if reserve1 > 0 else 0
        if ratio > 1000 or ratio < 0.001:
            return {
                'healthy': False,
                'reason': f'Extreme reserves ratio: {ratio:.2f}',
                'liquidity_usd': total_liquidity_usd
            }
        
        # Check pool hasn't been drained recently
        # (compare current reserves to initial LP)
        if token.lp_liquidity_kas:
            current_kas = kas_reserve / 1e18
            initial_kas = float(token.lp_liquidity_kas)
            drain_ratio = current_kas / initial_kas if initial_kas > 0 else 1
            
            if drain_ratio < 0.5:  # Pool drained by >50%
                return {
                    'healthy': False,
                    'reason': f'Pool significantly drained: {drain_ratio:.1%} of initial liquidity',
                    'liquidity_usd': total_liquidity_usd
                }
        
        return {
```

```javascript
class TransactionManager {
    constructor() {
        this.pendingTransactions = new Map();  // Track all pending txs
        this.maxRetries = 3;
        this.retryDelay = 5000;  // 5 seconds
    }
    
    async executeTrade(side, txData, options = {}) {
        const txId = this.generateTxId();
        
        try {
            // Stage 1: Gas estimation
            const gasEstimate = await this.estimateGasWithRetry(txData);
            txData.gas = Math.floor(gasEstimate * 1.2);  // 20% buffer
            
            // Stage 2: Submit transaction
            const txHash = await this.submitTransaction(txData, txId);
            
            // Stage 3: Wait for confirmation
            const receipt = await this.waitForConfirmation(txHash, options.timeout || 180);
            
            // Stage 4: Verify success
            if (!receipt.status) {
                throw new TransactionRevertedError(txHash, receipt);
            }
            
            // Stage 5: Update UI
            this.handleSuccess(side, receipt);
            
            return receipt;
            
        } catch (error) {
            return await this.handleError(error, side, txData, txId, options);
        } finally {
            this.pendingTransactions.delete(txId);
        }
    }
    
    async estimateGasWithRetry(txData, attempt = 1) {
        try {
            return await window.ethereum.request({
                method: 'eth_estimateGas',
                params: [txData]
            });
        } catch (error) {
            if (attempt < this.maxRetries) {
                await this.sleep(this.retryDelay);
                return this.estimateGasWithRetry(txData, attempt + 1);
            }
            throw new GasEstimationError(error);
        }
    }
    
    async submitTransaction(txData, txId) {
        try {
            const txHash = await window.ethereum.request({
                method: 'eth_sendTransaction',
                params: [txData]
            });
            
            // Track pending transaction
            this.pendingTransactions.set(txId, {
                hash: txHash,
                data: txData,
                submitted_at: Date.now(),
                status: 'pending'
            });
            
            return txHash;
            
        } catch (error) {
            if (error.code === 4001) {
                // User rejected
                throw new UserRejectedError();
            } else if (error.code === -32603) {
                // Insufficient funds
                throw new InsufficientFundsError(error);
            } else {
                throw new TransactionSubmissionError(error);
            }
        }

        const startTime = Date.now();
        
        while ((Date.now() - startTime) / 1000 < timeout) {
            try {
                const receipt = await window.ethereum.request({
                    method: 'eth_getTransactionReceipt',
                    params: [txHash]
                });
                
                if (receipt) {
                    return receipt;
                }
                
                // Check if stuck in mempool
                if ((Date.now() - startTime) / 1000 > 60) {
                    // After 60s, check if tx still pending
                    const tx = await this.getTransaction(txHash);
                    if (!tx) {
                        throw new TransactionDroppedError(txHash);
                    }
                }
                
                await this.sleep(2000);  // Poll every 2 seconds
                
            } catch (error) {
                if (error instanceof TransactionDroppedError) {
                    throw error;
                }
                // Network error, retry
                await this.sleep(5000);
            }
        }
        
        throw new TransactionTimeoutError(txHash, timeout);
    }
    
    async handleError(error, side, txData, txId, options) {
        console.error('Transaction error:', error);
        
        // Categorize error
        if (error instanceof UserRejectedError) {
            ModalManager.alert(
                'Transaction Cancelled',
                'You cancelled the transaction in your wallet.',
                'info'
            );
            return { cancelled: true };
            
        } else if (error instanceof InsufficientFundsError) {
            ModalManager.alert(
                'Insufficient Funds',
                'You don\'t have enough KAS to complete this transaction (including gas fees).',
                'error'
            );
            return { error: 'insufficient_funds' };
            
        } else if (error instanceof GasEstimationError) {
            // Transaction would revert - likely slippage or approval issue
            const diagnosis = await this.diagnoseFailure(txData, side);
            
            ModalManager.alert(
                'Transaction Would Fail',
                `This transaction cannot be completed: ${diagnosis.reason}
                
                Suggestions:
                ${diagnosis.suggestions.map(s => `• ${s}`).join('\n')}`,
                'error'
            );
            return { error: 'would_revert', diagnosis };
            
        } else if (error instanceof TransactionRevertedError) {
            // Transaction was mined but reverted
            const reason = await this.getRevertReason(error.receipt);
            
            ModalManager.alert(
                'Transaction Failed',
                `Transaction was submitted but failed on-chain: ${reason}
                
                Gas was consumed but trade did not execute.
                [View on Explorer](${EXPLORER_URL}/tx/${error.txHash})`,
                'error'
            );
            
            // Refund approval if swap failed
            if (side === 'sell' && this.wasApprovalStep(txId)) {
                await this.handleFailedSwapAfterApproval(txData);
            }
            
            return { error: 'reverted', reason, txHash: error.txHash };
            
        } else if (error instanceof TransactionTimeoutError) {
            // Transaction stuck in mempool
            const choice = await ModalManager.choice(
                'Transaction Delayed',
                `Transaction is taking longer than expected (${error.timeout}s).
                
                It may still complete, or you can:`,
                'Wait Longer',
                'Speed Up (Higher Gas)',
                'Cancel Transaction'
            );
            
            if (choice === 'Wait Longer') {
                return this.waitForConfirmation(error.txHash, 300);  // Wait 5 more min
            } else if (choice === 'Speed Up') {
                return this.speedUpTransaction(error.txHash, txData);
            } else {
                return this.cancelTransaction(error.txHash, txData);
            }
            
        } else if (error instanceof TransactionDroppedError) {
            // Transaction dropped from mempool (nonce too low, replaced, etc)
            const retry = await ModalManager.confirm(
                'Transaction Dropped',
                'Your transaction was dropped from the mempool. This can happen during network congestion. Retry?',
                'Retry',
                'Cancel'
            );

                await this.sleep(5000);
                return this.executeTrade(side, txData, {
                    ...options,
                    retryCount: (options.retryCount || 0) + 1
                });
            }
            
            return { error: 'dropped' };
            
        } else {
            // Unknown error
            ModalManager.alert(
                'Transaction Error',
                `An unexpected error occurred: ${error.message}
                
                Please try again or contact support if this persists.`,
                'error'
            );
            
            // Log to monitoring
            this.logError(error, txData, txId);
            
            return { error: 'unknown', details: error.message };
        }
    }
    
    async diagnoseFailure(txData, side) {
        """Diagnose why transaction would fail before submitting"""
        
        // Check common failure reasons
        const checks = await Promise.all([
            this.checkBalance(txData),
            this.checkApproval(txData, side),
            this.checkSlippage(txData),
            this.checkPoolExists(txData),
            this.checkGasPrice(txData)
        ]);
        
        const failures = checks.filter(c => !c.passed);
        
        if (failures.length === 0) {
            return {
                reason: 'Unknown - transaction estimation failed',
                suggestions: ['Try reducing trade size', 'Check network status']
            };
        }
        
        return {
            reason: failures.map(f => f.reason).join('; '),
            suggestions: failures.flatMap(f => f.suggestions)
        };
    }
    
    async speedUpTransaction(txHash, originalTxData) {
        """Increase gas price to speed up stuck transaction"""
        
        // Get current gas price
        const currentGasPrice = await window.ethereum.request({
            method: 'eth_gasPrice'
        });
        
        // Increase by 20%
        const newGasPrice = Math.floor(parseInt(currentGasPrice, 16) * 1.2);
        
        // Resubmit with same nonce but higher gas
        const speedUpTx = {
            ...originalTxData,
            gasPrice: `0x${newGasPrice.toString(16)}`
        };
        
        return this.submitTransaction(speedUpTx, this.generateTxId());
    }
    
    async cancelTransaction(txHash, originalTxData) {
        """Cancel stuck transaction by submitting 0-value tx with same nonce"""
        
        const cancelTx = {
            from: originalTxData.from,
            to: originalTxData.from,  // Send to self
            value: '0x0',
            gas: '0x5208',  // 21000 gas (minimum)
            gasPrice: await this.getHigherGasPrice(originalTxData.gasPrice),
            nonce: originalTxData.nonce
        };
        
        return this.submitTransaction(cancelTx, this.generateTxId());
    }
    
    async getRevertReason(receipt) {
        """Extract revert reason from failed transaction"""
        
        try {
            // Try to get revert reason from receipt
            const tx = await window.ethereum.request({
                method: 'eth_getTransactionByHash',
                params: [receipt.transactionHash]
            });
            
            // Call transaction to get revert reason
            const result = await window.ethereum.request({
                method: 'eth_call',
                params: [tx, receipt.blockNumber]
            });
            
            // Decode revert reason
            if (result.startsWith('0x08c379a0')) {
                // Standard revert with reason string
                const reason = this.web3.utils.toUtf8(result.slice(138));
                return reason;
            }
            
            return 'Transaction reverted (no reason provided)';
            
        } catch (error) {
            return 'Transaction reverted (reason unavailable)';
        }
    }
```

```python
class EventIndexer:
    def __init__(self):
        self.processed_blocks = set()  # In-memory cache
        self.lock = threading.Lock()
        self.reorg_detection_enabled = True
    
    def process_swap_event(self, event, token):
        """Idempotent swap event processing"""
        
        tx_hash = event['transactionHash'].hex()
        log_index = event['logIndex']
        
        # Create unique identifier for this event
        event_id = f"{tx_hash}:{log_index}"
        
        # Check if already processed (idempotency check)
        existing_trade = Trade.query.filter_by(
            transaction_hash=tx_hash,
            log_index=log_index
        ).first()
        
        if existing_trade:
            logger.debug(f"Event {event_id} already processed, skipping")
            return existing_trade
        
        # Atomic transaction
        try:
            with db.session.begin_nested():
                # Extract event data
                is_buy = event['args']['tokenOut'] == token.contract_address
                amount_in = event['args']['amountIn']
                amount_out = event['args']['amountOut']
                user_address = event['args']['recipient']
                
                # Create trade record with unique constraint fields
                trade = Trade(
                    token_id=token.id,
                    transaction_hash=tx_hash,
                    log_index=log_index,  # ← Important for uniqueness
                    block_number=event['blockNumber'],
                    type='buy' if is_buy else 'sell',
                    token_amount=amount_out if is_buy else amount_in,
                    kas_amount=amount_in if is_buy else amount_out,
                    user_address=user_address.lower(),
                    created_at=self.get_block_timestamp(event['blockNumber'])
                )
                
                db.session.add(trade)
                db.session.commit()
                
                logger.info(f"Processed swap event {event_id} for token {token.symbol}")
                
                return trade
                
        except IntegrityError:
            # Race condition hit - another worker already inserted
            db.session.rollback()
            logger.debug(f"Event {event_id} already processed by another worker")
            
            # Return existing record
            return Trade.query.filter_by(
                transaction_hash=tx_hash,
                log_index=log_index
            ).first()
    
    def process_block_range(self, from_block, to_block):
        """Process block range with reorg detection"""
        
        with self.lock:
            # Check if blocks already processed
            if all(b in self.processed_blocks for b in range(from_block, to_block + 1)):
                logger.debug(f"Blocks {from_block}-{to_block} already processed")
                return
        
        # Get events from blockchain
        events = self.fetch_events(from_block, to_block)
        
        # Detect potential reorg
        if self.reorg_detection_enabled:
            reorg_detected = self.detect_reorg(from_block)
            if reorg_detected:
                logger.warning(f"Reorg detected at block {from_block}, reprocessing")
                self.handle_reorg(from_block)
        
        # Process each event
        for event in events:
            token = self.get_token_from_event(event)
            if token and token.graduation_status == 'graduated':
                self.process_swap_event(event, token)
        
        # Mark blocks as processed
        with self.lock:
            self.processed_blocks.update(range(from_block, to_block + 1))
        
        # Prune old blocks from cache (keep last 1000)
        if len(self.processed_blocks) > 1000:
            self.processed_blocks = set(sorted(self.processed_blocks)[-1000:])
    
    def detect_reorg(self, block_number):

        # Get block hash from our database
        stored_hash = self.get_stored_block_hash(block_number)
```

```javascript
// approval_manager.js (NEW)

class ApprovalManager {
    constructor() {
        this.approvals = new Map();  // token → spender → amount
        this.pendingApprovals = new Map();  // txHash → approval data
        this.loadFromStorage();
    }
    
    async getApproval(tokenAddress, spenderAddress, userAddress) {
        """Get current approval with caching"""
        
        const cacheKey = `${tokenAddress}:${spenderAddress}:${userAddress}`;
        
        // Check cache first
        if (this.approvals.has(cacheKey)) {
            const cached = this.approvals.get(cacheKey);
            
            // Cache valid for 5 minutes
            if (Date.now() - cached.timestamp < 300000) {
                return cached.amount;
            }
        }
        
        // Fetch from blockchain
        const tokenContract = new ethers.Contract(tokenAddress, ERC20_ABI, provider);
        const allowance = await tokenContract.allowance(userAddress, spenderAddress);
        
        // Cache result
        this.approvals.set(cacheKey, {
            amount: allowance.toString(),
            timestamp: Date.now()
        });
        
        this.saveToStorage();
        
        return allowance.toString();
    }
    
    async requestApproval(tokenAddress, spenderAddress, amount, userAddress) {
        """Request token approval with state tracking"""
        
        const cacheKey = `${tokenAddress}:${spenderAddress}:${userAddress}`;
        
        // Check if approval already pending
        for (const [txHash, approval] of this.pendingApprovals) {
            if (approval.cacheKey === cacheKey && approval.amount >= amount) {
                // Approval already pending, wait for it
                return this.waitForApproval(txHash);
            }
        }
        
        // Build approval transaction
        const tokenContract = new ethers.Contract(tokenAddress, ERC20_ABI, signer);
        const tx = await tokenContract.approve(spenderAddress, amount);
        
        // Track pending approval
        this.pendingApprovals.set(tx.hash, {
            cacheKey: cacheKey,
            amount: amount.toString(),
            timestamp: Date.now(),
            status: 'pending'
        });
        
        this.saveToStorage();
        
        // Wait for confirmation
        const receipt = await tx.wait();
        
        // Update cache with new approval
        this.approvals.set(cacheKey, {
            amount: amount.toString(),
            timestamp: Date.now()
        });
        
        // Remove from pending
        this.pendingApprovals.delete(tx.hash);
        this.saveToStorage();
        
        return receipt;
    }
    
    async waitForApproval(txHash) {
        """Wait for pending approval to confirm"""
        
        const approval = this.pendingApprovals.get(txHash);
        if (!approval) {
            throw new Error('Approval not found');
        }
        
        // Poll for confirmation
        while (approval.status === 'pending') {
            const receipt = await provider.getTransactionReceipt(txHash);
            
            if (receipt) {
                if (receipt.status === 1) {
                    approval.status = 'confirmed';
                    this.saveToStorage();
                    return receipt;
                } else {
                    approval.status = 'failed';
                    this.pendingApprovals.delete(txHash);
                    this.saveToStorage();
                    throw new Error('Approval transaction failed');
                }
            }
            
            await new Promise(resolve => setTimeout(resolve, 2000));
        }
    }
    
    invalidateCache(tokenAddress, spenderAddress, userAddress) {
        """Invalidate cached approval after use"""
        const cacheKey = `${tokenAddress}:${spenderAddress}:${userAddress}`;
        this.approvals.delete(cacheKey);
        this.saveToStorage();
    }
    
    loadFromStorage() {
        """Load approvals from localStorage"""
        try {
            const stored = localStorage.getItem('approvals');
            if (stored) {
                const data = JSON.parse(stored);
                this.approvals = new Map(data.approvals || []);
                this.pendingApprovals = new Map(data.pending || []);
            }
        } catch (error) {
            console.error('Failed to load approvals from storage:', error);
        }
    }
    
    saveToStorage() {
        """Save approvals to localStorage"""
        try {
            localStorage.setItem('approvals', JSON.stringify({
                approvals: Array.from(this.approvals.entries()),
                pending: Array.from(this.pendingApprovals.entries())
            }));
        } catch (error) {
            console.error('Failed to save approvals to storage:', error);
        }
```

```javascript
// trade_impact_analyzer.js (NEW)

class TradeImpactAnalyzer {
    async analyzeTrade(token, amount, isBuy) {
        const analysis = {
            warnings: [],
            severity: 'none',  // 'none', 'low', 'medium', 'high', 'critical'
            proceed: true
        };
        
        // Get pool data
        const poolData = await this.getPoolData(token);
        
        // Check 1: Pool liquidity
        if (poolData.liquidity_usd < 5000) {
            analysis.warnings.push({
                type: 'low_liquidity',
                message: `⚠️ Very low liquidity: $${poolData.liquidity_usd.toFixed(0)}`,
                severity: 'high',
                explanation: 'Low liquidity pools have high price impact and volatility'
            });
            analysis.severity = 'high';
        }
        
        // Check 2: Trade impact
        const tradeValue = this.calculateTradeValue(amount, token);
        const impactRatio = tradeValue / poolData.liquidity_usd;
        
        if (impactRatio > 0.10) {
            analysis.warnings.push({
                type: 'high_impact',
                message: `⚠️ Large trade: ${(impactRatio * 100).toFixed(1)}% of pool`,
                severity: 'high',
                explanation: 'Your trade will significantly move the price'
            });
            analysis.severity = 'high';
        } else if (impactRatio > 0.05) {
            analysis.warnings.push({
                type: 'medium_impact',
                message: `⚠️ Notable trade: ${(impactRatio * 100).toFixed(1)}% of pool`,
                severity: 'medium',
                explanation: 'Your trade will have noticeable price impact'
            });
            if (analysis.severity === 'none') analysis.severity = 'medium';
        }
        
        // Check 3: Recent volatility
        const volatility = await this.getRecentVolatility(token);
        if (volatility > 20) {
            analysis.warnings.push({
                type: 'high_volatility',
                message: `⚠️ High volatility: ${volatility.toFixed(1)}% (1h)`,
                severity: 'medium',
                explanation: 'Price is moving rapidly - be cautious'
            });
            if (analysis.severity === 'none') analysis.severity = 'medium';
        }
        
        // Check 4: Pool age
        const poolAge = Date.now() - new Date(token.graduation_completed_at).getTime();
        const poolAgeHours = poolAge / (1000 * 60 * 60);
        
        if (poolAgeHours < 1) {
            analysis.warnings.push({
                type: 'new_pool',
                message: `⚠️ New pool: ${poolAgeHours.toFixed(1)} hours old`,
                severity: 'medium',
                explanation: 'New pools are more volatile and risky'
            });
            if (analysis.severity === 'none') analysis.severity = 'medium';
        }
        
        // Check 5: Unusual activity
        const unusualActivity = await this.detectUnusualActivity(token);
        if (unusualActivity) {
            analysis.warnings.push({
                type: 'unusual_activity',
                message: '⚠️ Unusual trading activity detected',
                severity: 'high',
                explanation: unusualActivity.reason
            });
            analysis.severity = 'high';
        }
        
        // Critical: Block trade if too risky
        if (analysis.severity === 'critical') {
            analysis.proceed = false;
        }
        
        return analysis;
    }
    
    async showImpactWarning(analysis, token, amount, isBuy) {
        if (analysis.warnings.length === 0) {
            return true;  // No warnings, proceed
        }
        
        // Build warning message
        const warningHTML = `
            <div class="trade-warnings ${analysis.severity}-severity">
                <h4>⚠️ Trade Warnings</h4>
                ${analysis.warnings.map(w => `
                    <div class="warning ${w.severity}">
                        <strong>${w.message}</strong>
                        <p>${w.explanation}</p>
                    </div>
                `).join('')}
                
                <div class="trade-summary">
                    <strong>Trade Summary:</strong>
                    <ul>
                        <li>You're ${isBuy ? 'buying' : 'selling'} ${amount} ${token.symbol}</li>
                        <li>Pool liquidity: $${analysis.pool_liquidity_usd.toFixed(0)}</li>
                        <li>Estimated price impact: ${(analysis.price_impact * 100).toFixed(2)}%</li>
                    </ul>
                </div>
                
                ${analysis.severity === 'high' ? `
                    <div class="recommendation">
                        <strong>Recommendation:</strong> Consider reducing trade size or waiting for more liquidity.
                    </div>
                ` : ''}
            </div>
        `;
        
        if (!analysis.proceed) {
            ModalManager.alert(
                'Trade Blocked',
                warningHTML + '<p><strong>This trade is too risky to execute.</strong></p>',
                'error'
            );
            return false;
        }
        
        const confirmed = await ModalManager.confirm(
            'Trade Warning',
            warningHTML,
            'Proceed Anyway',
            'Cancel'
        );
        
        return confirmed;
    }
}
```
