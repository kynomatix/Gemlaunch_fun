Why GraphQL ≠ REST API
GraphQL gives you:

✅ Flexible queries (get exactly what you need)
✅ Real-time subscriptions
✅ Batch operations
✅ Nested data in one request
✅ Strong typing

REST API limitations:

❌ Fixed endpoints (can't customize response)
❌ Multiple requests for related data
❌ Over-fetching or under-fetching data
❌ No real-time subscriptions

from gql.transport.requests import RequestsHTTPTransport

# THIS IS CORRECT!
BLOCKSCOUT_GRAPHQL = "https://explorer.testnet.kasplextest.xyz/graphiql"

transport = RequestsHTTPTransport(
    url=BLOCKSCOUT_GRAPHQL,
    use_json=True,  # Important!
    headers={
        "Content-Type": "application/json",
    },
)

client = Client(transport=transport, fetch_schema_from_transport=False)

    "query": """
        {

                types {
                    name
                }
            }
        }
    """
}

    "Content-Type": "application/json"
})

print(f"Status: {response.status_code}")
