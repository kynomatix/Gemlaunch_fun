### 2. Token Balances vs Transactions

**Problem:** The plan conflates transactions with token transfers.

**Reality:**
- `transactions()` = ETH/KAS transfers + contract interactions
- `tokenTransfers()` = ERC-20/KRC-20 token movements
- `tokenBalances()` = Current holder balances

**Fix - Get Token Transfers (not just transactions):**

```python
def get_token_transfers(self, contract_address, limit=100):
    """Get token transfer events (buy/sell trades)"""
    query = gql("""
        query GetTokenTransfers($address: AddressHash!, $first: Int!) {
            address(hash: $address) {
                tokenTransfers(first: $first, order: DESC) {
                    edges {
                        node {
                            amount
                            fromAddressHash
                            toAddressHash
                            tokenContractAddressHash
                            transactionHash
                            blockNumber
                            timestamp
                            transaction {
                                value
                                input
                            }
                        }
                    }
                }
            }
        }
    """)
    
    result = self.client.execute(query, {
        "address": contract_address,
        "first": limit
    })
    
    return [e['node'] for e in result['address']['tokenTransfers']['edges']]
```

### 3. Decoding Buy vs Sell from Input Data

**Problem:** Plan doesn't explain how to determine if a transaction is buy or sell.

**Solution:** Parse the transaction `input` field

```python
from eth_abi import decode

def parse_trade_type(transaction):
    """
    Decode transaction input to determine buy/sell
    
    Bonding curve contract methods:
    - buy(uint256 tokenAmount, uint256 maxKasAmount)
    - sell(uint256 tokenAmount, uint256 minKasAmount)
    """
    input_data = transaction['input']
    
    if not input_data or input_data == '0x':
        return None
    
    # First 4 bytes = method signature
    method_sig = input_data[:10]  # '0x' + 8 hex chars
    
    # Method signatures (keccak256 hash of function signature)
    BUY_SIG = '0xa1b2c3d4'  # Replace with actual buy() signature
    SELL_SIG = '0xe5f6g7h8'  # Replace with actual sell() signature
    
    if method_sig == BUY_SIG:
        return 'buy'
    elif method_sig == SELL_SIG:
        return 'sell'
    else:
        return 'unknown'

# Usage:
transfers = blockscout_client.get_token_transfers(contract_address)
for transfer in transfers:
    trade_type = parse_trade_type(transfer['transaction'])
    print(f"{trade_type}: {transfer['amount']} tokens")
```

**Better approach:** Look at the transfer direction
- Transfer TO pool address = SELL (user → pool)
- Transfer FROM pool address = BUY (pool → user)

```python
def get_trades_from_transfers(contract_address, pool_address):
    """Parse transfers to determine buys and sells"""
    transfers = blockscout_client.get_token_transfers(contract_address)
    
    trades = []
    for transfer in transfers:
        if transfer['toAddressHash'].lower() == pool_address.lower():
            # User sent tokens to pool = SELL
            trades.append({
                'type': 'sell',
                'trader': transfer['fromAddressHash'],
                'token_amount': transfer['amount'],
                'timestamp': transfer['timestamp'],
                'tx_hash': transfer['transactionHash']
            })
        elif transfer['fromAddressHash'].lower() == pool_address.lower():
            # Pool sent tokens to user = BUY
            trades.append({
                'type': 'buy',
                'trader': transfer['toAddressHash'],
                'token_amount': transfer['amount'],
                'timestamp': transfer['timestamp'],
                'tx_hash': transfer['transactionHash']
            })
    
    return trades
```

### 4. Missing: How to Get KAS Amount per Trade

**Problem:** Token transfers don't show how much KAS was paid.

**Solution:** Query the transaction value or decode logs

```python
def get_trade_details(transaction_hash):
    """Get full trade details including KAS amount"""
    query = gql("""
        query GetTransaction($hash: FullHash!) {
            transaction(hash: $hash) {
                hash
                value
                fromAddressHash
                toAddressHash
                input
                logs {
                    data
                    topics
                    address
                }
                tokenTransfers {
                    amount
                    tokenContractAddressHash
                }
            }
        }
    """)
    
    result = self.client.execute(query, {"hash": transaction_hash})
    tx = result['transaction']
    
    # KAS amount is in the transaction value
    kas_amount = int(tx['value']) / 1e18
    
    # Token amount is in the transfer
    token_transfer = tx['tokenTransfers'][0] if tx['tokenTransfers'] else None
    token_amount = int(token_transfer['amount']) if token_transfer else 0
    
    return {
        'kas_amount': kas_amount,
        'token_amount': token_amount,
        'trader': tx['fromAddressHash']
    }
```

### 5. Real-Time Updates: Missing WebSocket Implementation

**Problem:** Plan mentions subscriptions but doesn't show how to implement them.

**Fix:** Blockscout uses Phoenix WebSocket, not standard GraphQL subscriptions

```python
# Use polling instead of WebSocket for simplicity
import asyncio
from datetime import datetime

class RealtimeTradesMonitor:
    def __init__(self, contract_address):
        self.contract_address = contract_address
        self.last_block = None
        self.callbacks = []
    
    def on_new_trade(self, callback):
        """Register callback for new trades"""
        self.callbacks.append(callback)
    
    async def start_monitoring(self, interval=10):
        """Poll for new trades every N seconds"""
        while True:
            try:
                # Get recent transfers
                transfers = blockscout_client.get_token_transfers(
                    self.contract_address, 
                    limit=10
                )
                
                # Find new ones
                for transfer in transfers:
                    block_num = transfer['blockNumber']
                    if self.last_block is None or block_num > self.last_block:
                        # New trade detected
                        for callback in self.callbacks:
                            callback(transfer)
                        
                        self.last_block = max(self.last_block or 0, block_num)
                
                await asyncio.sleep(interval)
                
            except Exception as e:
                print(f"Error monitoring trades: {e}")
                await asyncio.sleep(interval)

# Usage:
monitor = RealtimeTradesMonitor('0xTokenAddress')

def handle_new_trade(trade):
    print(f"New trade: {trade['amount']} tokens")
    # Update frontend, send WebSocket message, etc.

monitor.on_new_trade(handle_new_trade)
asyncio.run(monitor.start_monitoring(interval=10))
```

### 8. Error Handling Needs to Be More Robust

**Problem:** Simple try/except won't handle all GraphQL errors.

**Fix:**

```python
from gql.transport.exceptions import TransportQueryError
import time

class BlockscoutClient:
    def __init__(self):
        self.max_retries = 3
        self.retry_delay = 2
    
    def execute_with_retry(self, query, variables):
        """Execute GraphQL query with retry logic"""
        for attempt in range(self.max_retries):
            try:
                return self.client.execute(query, variable_values=variables)
            
            except TransportQueryError as e:
                # GraphQL error (e.g., invalid address)
                logging.error(f"GraphQL query error: {e}")
                return None
            
            except Exception as e:
                # Network error, API down, etc.
                logging.warning(f"Attempt {attempt + 1} failed: {e}")
                if attempt < self.max_retries - 1:
                    time.sleep(self.retry_delay * (attempt + 1))
                else:
                    logging.error("All retries failed")
                    return None
    
    def get_token_transfers(self, contract_address, limit=100):
        """Get token transfers with error handling"""
        query = gql("""...""")
        
        result = self.execute_with_retry(query, {
            "address": contract_address,
            "first": limit
        })
        
        if result is None:
            # Return empty list instead of crashing
            return []
        
        return [e['node'] for e in result['address']['tokenTransfers']['edges']]
```
