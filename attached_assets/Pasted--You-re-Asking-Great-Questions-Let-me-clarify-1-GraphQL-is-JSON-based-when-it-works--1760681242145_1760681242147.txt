### 1. GraphQL is JSON-based (when it works)

**GraphQL query:**
```graphql
{
  address(hash: "0x123") {
    transactions {
      hash
    }
  }
}
```

**Response is JSON:**
```json
{
  "data": {
    "address": {
      "transactions": [
        { "hash": "0xabc..." }
      ]
    }
  }
}
```

So yes, GraphQL returns JSON (not plain text).
