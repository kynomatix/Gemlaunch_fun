### M-8: Quote Data Structure Mismatch (Will Cause Runtime Error)
**Location**: Section 3.3, quote storage vs usage  
**Severity**: MEDIUM - Trade execution will fail with "undefined" error

**The Problem**: Quote is stored in nested structure but accessed directly.

**Storage** (line in NC-3 fix):
```javascript
window.lastQuote = {
    data: quote,           // ✅ Quote nested inside 'data'
    timestamp: Date.now(),
    mode: TokenDetail.currentTradeMode
};
```

**Usage** (multiple places):
```javascript
// ❌ WRONG - Accessing as if quote is at top level
const slippageBps = window.lastQuote?.auto_slippage_bps || 50;
```

**Result**: `window.lastQuote.auto_slippage_bps` is `undefined`, always defaults to 50, ignoring contract's auto-slippage calculation.

**Fix**:
```javascript
// Option 1: Access nested data property
const slippageBps = window.lastQuote?.data?.auto_slippage_bps || 50;

// Option 2: Store flat (RECOMMENDED - cleaner)
window.lastQuote = {
    ...quote,              // Spread quote properties at top level
    timestamp: Date.now(),
    mode: TokenDetail.currentTradeMode
};

// Then access works as expected:
const slippageBps = window.lastQuote?.auto_slippage_bps || 50;
```

**All Places to Fix**:
```javascript

// In executeTrade() for SELL:

```

**Recommended Fix** (change storage, not all access points):
```javascript

if (quote.success) {
    window.lastQuote = {
        ...quote,              // ✅ Flatten the structure
        timestamp: Date.now(),
        mode: TokenDetail.currentTradeMode
    };
    
    // ... rest of code
```

### M-9: Sell Quote Uses Wrong Input Parameter
**Location**: Section 3.3, Step 1 (updateTokenAmount function)  
**Severity**: MEDIUM - Sell quotes will fail with "invalid parameter" error

**The Problem**: Sell quotes need `token_amount` but code passes `kas_amount` for both buy and sell.

**Current Code**:
```javascript
async function updateTokenAmount() {
    const kasAmount = parseFloat(document.getElementById('kasAmount').value) || 0;
    
    // ... validation ...
    
    const quote = await window.txManager.getQuote(
        TokenDetail.currentTradeMode, // 'buy' or 'sell'
        {
            token_address: window.tokenContractAddress,
            kas_amount: kasAmount  // ❌ WRONG for sell mode!
        },
        quoteAbortController.signal
    );
}
```

**Why It's Wrong**:
- BUY mode: User enters KAS → needs `kas_amount` ✅
- SELL mode: User enters tokens → needs `token_amount` ❌

**Backend Expects**:
```python
@app.route('/api/trade/quote-sell', methods=['POST'])
def api_quote_sell():
    data = request.get_json()
    
    quote = web3_service.get_sell_quote(
        token_address=data['token_address'],
        token_amount=data['token_amount']  # ← Expects this!
    )
```

**Fixed Implementation**:
```javascript
async function updateTokenAmount() {
    const action = TokenDetail.currentTradeMode; // 'buy' or 'sell'
    
    // Get the appropriate input amount based on mode
    let params = {
        token_address: window.tokenContractAddress
    };
    
    if (action === 'buy') {
        // BUY: User enters KAS, gets token amount
        const kasAmount = parseFloat(document.getElementById('kasAmount').value) || 0;
        
        if (kasAmount <= 0) {
            document.getElementById('tokenAmount').value = 0;
            clearFeeBreakdown();
            return;
        }
        
        params.kas_amount = kasAmount;
        
    } else { // sell
        // SELL: User enters tokens, gets KAS amount
        const tokenAmount = parseFloat(document.getElementById('tokenAmount').value) || 0;
        
        if (tokenAmount <= 0) {
            document.getElementById('kasAmount').value = 0;
            clearFeeBreakdown();
            return;
        }
        
        params.token_amount = tokenAmount;
    }
    
    // Cancel previous request if still pending
    if (quoteAbortController) {
        quoteAbortController.abort();
    }
    quoteAbortController = new AbortController();
    
    // Debounce API calls (300ms)
    clearTimeout(quoteTimeout);
    quoteTimeout = setTimeout(async () => {
        try {
            showQuoteLoading();
            
            const quote = await window.txManager.getQuote(
                action,
                params,  // ✅ Now has correct parameter for each mode
                quoteAbortController.signal
            );
            
            if (quote.success) {
                // Update the OUTPUT field based on mode
                if (action === 'buy') {
                    // Show tokens user will receive
                    document.getElementById('tokenAmount').value = 
                        Math.floor(quote.tokens_out);
                } else { // sell
                    // Show KAS user will receive
                    document.getElementById('kasAmount').value = 
                        quote.kas_out.toFixed(6);
                }
                
                // Display fee breakdown
                displayFeeBreakdown({
                    antiBotFee: quote.fees.anti_bot || 0,
                    platformFee: quote.fees.platform || 0,
                    creatorFee: quote.fees.creator || 0,
                    priceImpact: quote.price_impact_percent || 0
                });
                
                // Store quote for later use (with correct structure)
                window.lastQuote = {
                    ...quote,  // ✅ Flatten structure
                    timestamp: Date.now(),
                    mode: action
                };
                
                // Update USD value (works for both modes)
                const kasValue = action === 'buy' 
                    ? params.kas_amount 
                    : quote.kas_out;
                const usdAmount = kasValue * TokenDetail.kasToUsd;
                document.querySelector('.input-addon').textContent = 
                    `$${usdAmount.toFixed(2)} USD`;
            }
            
        } catch (error) {
            if (error.name === 'AbortError') {
                return; // Request cancelled, ignore
            }
            console.error('Quote failed:', error);
            showQuoteError(error.message);
        } finally {
            hideQuoteLoading();
        }
    }, 300);
}
```

## 🔵 **LOW SEVERITY / OPTIMIZATION**

### L-6: Gas Estimation Uses Oracle Address
**Location**: M-5 fix, estimate_trade_gas()  
**Issue**: Gas estimates may be slightly inaccurate

**Current**:
```python
.estimate_gas({
    'from': self.oracle_account.address,  # ← Not the actual sender
    'value': Web3.to_wei(params['kas_amount'], 'ether')
})
```

**Why It Matters**: Gas costs can vary based on storage operations (SSTORE costs differ for new vs existing values). Using oracle address instead of actual user might give different gas estimate.

**Better** (but not critical):
```python
# If user address is available in params
.estimate_gas({
    'from': params.get('from_address', self.oracle_account.address),
    'value': Web3.to_wei(params['kas_amount'], 'ether')
})
```

But this requires passing user address from frontend, adding complexity. The current approach is acceptable since gas differences are usually small (<5%).
