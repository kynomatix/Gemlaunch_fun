### Issue 3: Dangerous Superseded Sections
**Severity**: 🟡 HIGH  
**Impact**: Agent may copy outdated code

**Problem**: Superseded sections are not properly quarantined. Current markers are insufficient:

**Current Approach** (WEAK):
```markdown
## ⚠️ SUPERSEDED SECTION - DO NOT USE
[2,000 lines of outdated code]
```

**Why This Fails**:
- AI agents scan for code patterns, not warning headers
- No visual separation (line breaks, borders)
- Superseded code looks identical to current code
- Search results show superseded code first (earlier in file)

**Example Trap**:
```markdown
Line 1655: ## Sell Function (AUDIT FIX v3)
[Complete, working-looking implementation]

❌ Agent sees this first in search
❌ Looks complete and correct
❌ Missing v4 KAS-based fees fix
❌ Will break fee withdrawals
```

**Fix Required**:
1. Move ALL superseded code to separate appendix file (`AUDIT_HISTORY.md`)
2. OR wrap in collapsed sections with bold red headers
3. OR use code fence with `txt` (not `solidity`) to prevent syntax highlighting
