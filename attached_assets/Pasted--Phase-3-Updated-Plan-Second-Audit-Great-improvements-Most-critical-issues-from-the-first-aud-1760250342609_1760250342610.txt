## 🔴 **NEW CRITICAL ISSUES**

### NC-1: Token Approval Missing for Sell Transactions
**Location**: Section 3.3, sell flow  
**Severity**: CRITICAL - Sell transactions will fail without this

**Problem**: Before selling tokens, users must approve the BondingCurvePool contract to spend their tokens. This entire step is missing.

**How ERC20 Sells Work**:
```
1. User owns 1000 tokens
2. User must approve BondingCurvePool: "You can spend 1000 of my tokens"
3. THEN user can call sellTokens()
```

**Fix Required**:
```javascript
async function executeTrade() {
    // ... existing code ...
    
    if (action === 'sell') {
        // CHECK APPROVAL FIRST
        const tokenContract = new ethers.Contract(
            window.tokenContractAddress,
            ['function allowance(address,address) view returns (uint256)',
             'function approve(address,uint256) returns (bool)'],
            provider.getSigner()
        );
        
        const currentAllowance = await tokenContract.allowance(
            wallet.address,
            window.tokenContractAddress  // BondingCurvePool address
        );
        
        const tokenAmountWei = ethers.utils.parseEther(tokenAmount.toString());
        
        // If insufficient allowance, request approval first
        if (currentAllowance.lt(tokenAmountWei)) {
            const approveConfirmed = await ModalManager.confirm(
                'Approval Required',
                `You need to approve the contract to spend your ${TokenDetail.tokenSymbol} tokens.<br>
                 <small>This is a one-time approval per token.</small>`,
                'Approve'
            );
            
            if (!approveConfirmed) return;
            
            // Execute approval transaction
            showTradeStatus('Requesting token approval...');
            const approveTx = await tokenContract.approve(
                window.tokenContractAddress,
                ethers.constants.MaxUint256  // Approve infinite (standard practice)
            );
            
            showTradeStatus('Waiting for approval confirmation...');
            await approveTx.wait();
            showTradeStatus('Approval confirmed! Proceeding with sell...');
        }
        
        // NOW proceed with sell transaction
        params = { ... };
    }
    
    // Execute trade...
}
```

### NC-3: Quote Staleness Race Condition
**Location**: Section 3.3, quote storage  
**Severity**: HIGH - Users could execute with stale prices

**Problem**: `window.lastQuote` is stored globally but never validated for staleness. If user switches tabs or waits, quote could be outdated.

**Fix**:
```javascript
// Store quote with timestamp
window.lastQuote = {
    data: quote,
    timestamp: Date.now(),
    mode: action  // 'buy' or 'sell'
};

// In executeTrade(), validate quote is fresh
function isQuoteFresh(maxAgeSeconds = 30) {
    if (!window.lastQuote) return false;
    
    const age = (Date.now() - window.lastQuote.timestamp) / 1000;
    const correctMode = window.lastQuote.mode === TokenDetail.currentTradeMode;
    
    return age < maxAgeSeconds && correctMode;
}

async function executeTrade() {
    // Validate quote freshness
    if (!isQuoteFresh()) {
        ModalManager.alert(
            'Quote Expired',
            'Please wait for updated quote...',
            'warning'
        );
        await updateTokenAmount();  // Refresh quote
        return;
    }
    
    // ... rest of trade execution
}
```
