### **1. Fee Distribution Math Error - CRITICAL**

**PROBLEM:** Fees are calculated on the FULL `msg.value`, but then subtracted. This means:
- User sends 100 KAS
- Platform fee: 1 KAS (1%)
- Creator fee: 0.5 KAS (0.5%)

**But then:**

**FIX:**

### **2. Bonding Curve Price Manipulation - CRITICAL**

Your midpoint pricing formula is **WRONG**:

```solidity
// CURRENT (BROKEN)
function quoteBuy(uint256 ethAmount) public view returns (uint256) {
    uint256 currentPrice = getCurrentPrice();
    uint256 tokenAmount = ethAmount * currentPrice / 1e18;
    
    // This is circular logic!
    tokensPerETH = (remainingTokens - (tokenAmount / 2)) * 1e18 / 
                   (address(this).balance + (ethAmount / 2));
}
```

**PROBLEM:** 
1. You calculate `tokenAmount` using current price
2. Then use that `tokenAmount` to calculate a new price
3. **But you never USE that new price to recalculate tokens!**

This is **not** midpoint pricing. It's current price with a broken adjustment.

**CORRECT MIDPOINT PRICING:**

```solidity
function quoteBuy(uint256 kasIn) public view returns (uint256 tokensOut) {
    uint256 poolTokens = balanceOf(address(this));
    uint256 poolKas = address(this).balance;
    
    // Constant product: k = poolTokens * poolKas
    uint256 k = poolTokens * poolKas;
    
    // After buy: k = (poolTokens - tokensOut) * (poolKas + kasIn)
    // Solve for tokensOut:
    uint256 newPoolKas = poolKas + kasIn;
    uint256 newPoolTokens = k / newPoolKas;
    tokensOut = poolTokens - newPoolTokens;
    
    // Safety: ensure we don't drain pool
    require(tokensOut < poolTokens, "Exceeds available supply");
}

function quoteSell(uint256 tokensIn) public view returns (uint256 kasOut) {
    uint256 poolTokens = balanceOf(address(this));
    uint256 poolKas = address(this).balance;
    
    uint256 k = poolTokens * poolKas;
    
    uint256 newPoolTokens = poolTokens + tokensIn;
    uint256 newPoolKas = k / newPoolTokens;
    kasOut = poolKas - newPoolKas;
    
    require(kasOut < poolKas, "Exceeds available KAS");
}
```

**Why this matters:** Your current formula can be gamed. Someone can find edge cases where they extract more tokens than they should.

### **4. Graduation Front-Running Attack - HIGH**

```solidity

    return pool.totalRaised() >= GRADUATION_THRESHOLD && !pool.graduated();
```

**PROBLEM:**

**Attack scenario:**

- **Graduation happens with less liquidity than expected**

**FIX:** Auto-graduate in the buy function, don't allow external trigger:

```solidity
function buyTokens() external payable nonReentrant {

        _graduateInternal();
    }

// Remove external graduate() function entirely
```
